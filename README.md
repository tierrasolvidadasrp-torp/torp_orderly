# TORP ORDERLY

<img width="2414" height="1760" alt="Gemini_Generated_Image_t6pnd2t6pnd2t6pn" src="https://github.com/user-attachments/assets/b234143f-c1b3-4c73-998f-04fc8dba623b" />

An immersive 1889 patient recovery and medical treatment system for RedM. Designed to replace instant respawns with full physical transport, clinic intake, and doctor-led revives.

## Features
* **Native Body Carry:** Utilizes RDR3 native tasking (`SCRIPT_TASK_CARRIABLE`) for authentic physical retrieval and transport to the clinic.
* **Doctor Treatment & Revive:** Full clinic integration allowing doctors/orderlies to stabilize, treat wounds, and revive unconscious patients.
* **Low-FPS Optimized:** Synchronous timing loops eliminating frame-rate desync and progress bar failures on low-end hardware.
* **RSG Framework Ready:** Native compatibility with RSG player states and inventory items.

## Installation
1. Place `torp_orderly` inside your `resources` folder.
2. Add `ensure torp_orderly` to your `server.cfg`.
