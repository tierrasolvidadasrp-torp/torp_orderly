# TORP ORDERLY

![Banner](torp_orderly.jpg)

An immersive 1889 patient recovery system for RedM featuring realistic NPC retrieval and clinic transport mechanics.

## Features
* **Native Body Carry:** Utilizes RDR3 native tasking (`SCRIPT_TASK_CARRIABLE`) for authentic physical carrying and transport.
* **Low-FPS Optimized:** Deterministic timing loop eliminating UI/client desync on low-performance clients.
* **RSG Ready:** Native integration with RSG medical and character systems.

## Installation
1. Drop `torp_orderly` into your `resources` directory.
2. Add `ensure torp_orderly` to your `server.cfg`.
